# Strawbelle Sport — E-commerce UI

Proyecto frontend para una tienda con enfoque deportivo, desarrollado con React. Está orientado a presentar productos y contenido de marca mediante una interfaz visual, navegación web y estilos adaptables.

## Enfoque

- Presentación visual de una marca deportiva.
- Interfaz construida con React y componentes reutilizables.
- Navegación entre las secciones de la experiencia.
- Diseño adaptable a diferentes tamaños de pantalla.
- Uso de iconos y notificaciones para reforzar la interacción.

## Tecnologías

- React 18
- JavaScript
- Tailwind CSS
- React Router
- React Icons
- React Hot Toast
- Create React App

## Requisitos

- Node.js
- npm

## Instalación y ejecución

```bash
git clone https://github.com/miguelagcz/strawbelle.sport.git
cd strawbelle.sport
npm install
npm start
```

Create React App mostrará la dirección local de desarrollo, normalmente http://localhost:3000.

Para generar una compilación de producción:

```bash
npm run build
```

## Qué demuestra

Este proyecto permite revisar el uso de React para estructurar una interfaz, la organización de componentes, la navegación frontend y el diseño responsive. Las operaciones comerciales reales requieren servicios adicionales si no están incluidas en el repositorio.
