# Strawbelle Sport

Sitio web enfocado en la presentación de una marca/proyecto deportivo, con una interfaz visual y responsive orientada a mostrar contenido de forma clara y atractiva.

## ✨ Características

- Diseño responsive.
- Interfaz visual enfocada en contenido deportivo.
- Estructura de navegación web.
- Presentación de contenido e imágenes.
- Adaptación para diferentes tamaños de pantalla.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript

## 🚀 Cómo ejecutarlo

Clona el repositorio y abre el proyecto en tu navegador.

```bash
git clone https://github.com/miguelagcz/strawbelle.sport.git
```
